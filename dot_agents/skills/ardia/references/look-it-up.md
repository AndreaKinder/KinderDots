# Look it up

- `--port N` anywhere on the line (or `ARDIA_PORT`). Write `ardia browse` out in each command. Exit 2: Ardia isn't reachable; its message says what to ask the user.
- The rest of the browser and profile: `ardia methods` lists, `ardia call <name>` acts (`automation.md`); `ardia browse cdp <Domain.method>` sends any DevTools call.
- `ardia browse <command> --help`. `references/troubleshooting.md`: input that doesn't land, background tabs, refusals, sessions, exit codes. `automation.md`: tabs and groups (`ardia tabs --usage`), events, hooks. `userscripts.md`, `config.md` (looks: `ardia theme set`), `daily-reports.md`.
